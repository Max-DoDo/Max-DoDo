### 2.[Student-Wellbeing-System](https://github.com/Max-DoDo/Student-Wellbeing-System)

### 3. [WOW-PaoMo](https://github.com/Max-DoDo/WOW-PaoMo)
- A personal project for experimenting with World of Warcraft addon development, Python, computer vision, and communication between Lua and external programs.
- The plugin reads certain game data, converts it into strange little squares, reads those squares back in—seemingly without a clear reason—and decodes the information externally.
- Additionally, the plugin includes a keyboard controller of unknown purpose.
- Still under development.

### 4. [Stardew Valley Auto Fishing](https://github.com/Max-DoDo/Stardew-Valley-Auto-Fishing-Tool)
- A Python project that attempts to automatically play the fishing minigame in Stardew Valley.
- Uses OpenCV for UI detection, fish detection, green-bar tracking, and other computer vision tasks.
- Includes experiments with rule-based control and reinforcement learning.
- The long-term goal is to build an agent that can actually learn how to fish instead of me spending my own time doing it.
- Still experimental, and the fish occasionally has better decision-making skills than the program.

### 5. [Data Insights Dashboard for COVID19](https://github.com/Max-DoDo/Data-Insights-Dashboard-for-COVID19)
- A Python data analysis project based on COVID-19 data.
- Includes data cleaning, processing, visualisation, and analysis of patterns within the dataset.
- Probably one of the few projects here where strange numbers are not necessarily caused by my code.

### 6. [The-World-Conquest](https://github.com/Max-DoDo/The-World-Conquest)

- A group software engineering project developed using Unity and C#.
- A PC adaptation of the classic Risk-style board game, originally based on a version produced by Watson Games.
- Includes the basic systems required for territory control, player interaction, and turn-based gameplay.
- Developed as part of the `G6046: Software Engineering` group project.
